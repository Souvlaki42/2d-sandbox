# 2D Sandbox

A 2D sandbox game like Terraria, made with Godot 4.7+.

![Preview screenshot](screenshots/preview.png)

## Features

- Terrain generation
- Prop generation (trees, flowers, rocks etc)
- Ore generation
- Biomes
- Skins
- Crosshairs
- Tile drops
- Player
